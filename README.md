# 双语译读

macOS 原生 PDF 左右对照翻译应用，当前版本 0.12.0。

- 原文与译文左右对照、同步滚动、段落悬停关联高亮。
- 自定义兼容 API、多翻译源配置、系统钥匙串保存密钥。
- 苹果系统翻译，以及“苹果初译 + AI 校对”模式与自定义校对要求。
- 分栏排版、出版信息保留、本地缓存、停止后继续、完成页面译文导出。

## 构建

需要 macOS、Xcode 命令行工具及支持 Translation 框架的 SDK。构建目标为 Apple Silicon，最低 macOS 14；苹果翻译和混合模式需要 macOS 15+。

```sh
zsh src/build.sh
```

生成根目录下的 `双语译读.app`，脚本会临时签名并运行自检。打开后，在“翻译设置”中配置翻译源。混合模式会将原文和苹果初稿发送到配置的 API。

当前支持提取有文字层的 PDF；扫描件尚不支持 OCR。复杂图表排版仍可能需要适配。AI 校对不保证无误或比纯 AI 更快，真实整篇速度和质量尚未完成验收。

详细版本记录与用法见 `使用说明.txt`。仓库不包含 API 密钥、用户 PDF 或翻译缓存。
