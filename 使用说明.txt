双语译读 0.5.0 — 原版结构对照

Apple 芯片 Mac，macOS 14 或更新版本。本地构建、临时签名，尚未进行开发者公证。
退出正在运行的旧版本，再打开新版「双语译读.app」。不需要额外运行环境。

使用
1. 翻译设置：填写 OpenAI 兼容 API 地址、密钥、模型 ID、目标语言和可选术语。
2. 测试连接只发送一句示例文字，不发送 PDF；可能产生少量费用。
3. 打开文字型 PDF，点击翻译本页或全文翻译。
4. 左侧保留原页，右侧在对应文字块位置绘制译文，尚未翻译的区域继续显示原文。
5. 鼠标悬停或点击任意一侧的文字块，两边同时黄色高亮。青色圆环表示另一侧的相对位置。
6. 左右共用滚动区域；使用缩放滑块放大，或点击「适合窗口」。用页码旁箭头切页。
7. 底部显示所指段落的完整原文及译文，可选择复制。右页内容过长时自动缩字，极小字区域标橙框，可在底部阅读完整内容。
8. 「本页重译」清除本页对应缓存；随后点击「翻译本页」重新请求。
9. 「导出译文」仍导出按页组织的纯文本。

版本变化
0.2.0 改为逐文字块翻译，保存段落坐标与原译文对应关系；尽量保留页面尺寸、分栏、标题位置、图形及背景。
左右同步滚动、同步缩放，双向段落高亮与对侧位置指示。
错误弹窗继续展示服务端错误详情并遮蔽当前密钥及常见密钥格式。

缓存与费用
旧版整页译文没有块级对应关系，不强行套用到新版版式。旧缓存保留，新版首次翻译需重新请求。
逐文字块翻译的请求次数通常多于旧版；中断后已完成的块和片段可继续使用。
密钥按 API 请求地址保存在 macOS 钥匙串，重启自动读取。首次升级后需重新填写一次并点击保存设置。清空密钥并保存可删除当前地址的密钥。钥匙串可能显示系统授权提示；拒绝访问会明确报错。应用不能改变服务商设置的密钥有效期。普通配置与原有 API 设置保留。
仅点击翻译或测试连接时发送请求。全文翻译会向你设置的服务发送所选文档文字和术语偏好。
译文缓存为本地未加密 JSON，存放于 ~/Library/Application Support/BilingualReader/。

实际范围
这是段落级对应，不是英文单词与中文词语的逐词对齐。圆环只是段内相对位置示意。
当前按单页双栏对照显示，使用共享滚动；尚未实现整篇多页连续长卷。
原页与图形采用页面图像显示，译文在其上按块覆盖；不是可编辑的原版 PDF 重建。
原始字体不保证一致。复杂公式、表格、透明或彩色文字背景和极密集排版仍可能出现遮盖或识别偏差。
文字块划分依赖 PDFKit 和几何规则，复杂多栏文档可能需要进一步适配。
扫描 PDF 暂无 OCR；带页面旋转标记的 PDF 需先规范化方向，否则会明确提示。
尚无排版译文 PDF 导出、逐词对齐、自动模型列表和跨段上下文记忆。

验证
已通过编译、核心错误处理自测，以及无窗口版式渲染测试。
使用包含双栏、灰底摘要、标题、图形的合成 PDF，检查块 ID、每个块的双向命中、放大后的定位及左右几何一致性，并人工查看输出图片。
本版没有使用真实服务翻译用户论文。服务端 model_not_found 仍需使用服务商实际支持的模型 ID 解决。

源码
「双语译读源码」中的 main.swift、Layout.swift、Credentials.swift 和 build.sh。
安装 Xcode 命令行工具后运行 ./build.sh 重新构建并运行核心自测。

0.3.0 排版优化
新翻译要求模型整理 PDF 断行与段落；已完成的页面可点击「AI 优化排版」。该操作按块发送现有译文到已配置 API，会产生调用费用。
优化结果只有空白字符变化时才会采用，改动正文、数字或标点将拒绝采用该块；已完成的其他块会保留。
字号与行距由本机根据文字块空间自动适配，保留结构而非强行拉伸填满页面。复杂表格、公式和段落识别偏差仍可能存在。
0.2.0 的块级缓存继续沿用，现有译文可以直接优化，无需全部重译。
验证新增：仅空白变化校验及数值改动拒绝；使用独立随机测试项验证钥匙串保存、读取、更新、删除。尚未对用户真实 API 执行 AI 排版请求。

0.4.0 修复
按 PDF 字符选择坐标重新分行、分栏，再根据首行缩进、行距和段间距组成段落，修复双栏同高文字被当成一行，以及中文正文拆成单行的问题。
目标语言已经与正文相同时，高置信度识别后直接保留原文，避免中文正文再次被翻成英文；该检查目前支持中英文常用目标语言名称。
正文不再无限缩小到 4pt，空间不足时保留可读字号并显示「完整译文见下方」。
段落结构版本已更新，旧缓存保留但不复用，相关页面需要重新翻译。钥匙串密钥不受影响。
新增回归测试覆盖中文两字缩进、大行距、左右栏交错和段间分离，并检查双向命中与渲染。未获得截图对应的原 PDF，尚未对该真实文档验证。

0.5.0 WPS 样式参考
使用用户提供的 32 页原译文交替 PDF 核对版式，中文正文改用宋体风格，正文优先沿用原字号（常见为 10pt）。
已完成翻译的同栏连续正文段落，在原区域内顺序重排，使用统一字号和段间距；空间不足时保留原来的溢出提示。
高亮和对侧圆环使用重排后的实际段落位置，不要求左右段落高度相同。图片、栏结构和页眉页脚保留。
在该真实文件的首页，用 WPS 现成的目的、方法、结果、结论四段译文进行本地预览与命中测试；未调用 API，不代表已验证全部 32 页。预览中其他区域保留英文。
现有 0.4.0 译文缓存继续使用，打开相同原文即可应用新排版；本次不需要因排版升级而重新翻译。
本版仍不输出 WPS 那种原译文交替的双语 PDF，导出功能保持纯文本。


0.6.0 多翻译源
在翻译设置中点击“新增翻译源”，填写名称、API 地址、模型和密钥，保存后从主界面的“翻译源”切换。每次翻译使用一个源，不会同时向多个服务发送文档。支持 OpenAI 兼容 Chat Completions API，普通聊天网页不能直接使用。
每个翻译源分别保存密钥到 macOS 钥匙串。同一 API 地址可以保存多个模型/密钥配置。已有单源设置首次启动时自动迁移；切换设置窗口中的源前请保存修改。地址、模型、目标语言和术语相同时复用译文缓存。
苹果系统翻译：技术上可通过 macOS 15+ 的 Translation 框架集成；本版本尚未提供该引擎。


0.7.0 苹果系统翻译
退出旧版后打开新版，在主界面“翻译源”选择“苹果系统翻译”，点击“翻译本页”或“翻译全文 / 继续”。无需填写地址、模型或密钥。
需要 macOS 15 或更新版本。首次翻译缺少语言包时，系统会询问并下载；语言包就绪后在本机翻译。下载语言包需要网络，具体语言组合由系统支持情况决定。
可在翻译设置中更改目标语言，例如简体中文、繁体中文、英语、日语等，或输入语言代码。点击“测试连接”可用一句英语示例测试英译中。
苹果源保留左右同步、段落高亮、本地自动排版、缓存、停止/继续和文本导出。它不支持自定义术语指令和“AI 优化排版”；需要这些功能时切换自定义 API 源。
验证范围：编译、自测、旧配置读取、引擎缓存隔离、请求取消及重试测试通过；尚未在窗口内完成语言包下载及真实翻译验收。


0.7.1 苹果翻译短文本识别修复
修复 PDF 页眉、作者等短文字块因语言预检查失败而中断的问题（TranslationErrorDomain / 21）。短块参考整页语言；无法确定时由系统翻译会话处理语言选择。明确语言后先准备语言包，再翻译。错误提示增加失败阶段及错误标识。
已通过短页眉语言回退、未知语言处理、取消与重试回归测试。尚未完成系统语言包及真实整页翻译验收。
退出旧版、重新打开 0.7.1，选择苹果系统翻译后点击翻译本页即可重试。


0.8.0 完整阅读排版
取消橙色截断框和“完整译文见下方”。合并段内单个硬换行，保留空行分段，使用正常行距。译文超出原位置时延长右侧页面并下移后续内容，保持可读字号；右侧可能长于原页。已有译文缓存可直接使用，无需重新翻译。
已检查参考 PDF 的四段译文及长段落溢出、双向高亮与缩放。复杂图表跨越扩展区域时仍需进一步检查。


0.8.1 苹果翻译语言选择停滞修复
系统日志表明此前短文本反复触发原文语言选择，且系统扩展连接中断。现在无法可靠识别时直接提示设置原文语言，不再进入系统的语言选择弹窗；已安装语言包不重复准备。
英文论文：翻译设置 → 选择苹果源 → 原文语言选“英语” → 保存 → 翻译本页或全文继续。更改原文语言使用独立缓存。
保留 0.8.0 完整译文排版。已通过编译、明确语言请求和未知语言不启动会话、取消重试测试；实际整篇速度尚未实测。


0.8.2 修正论文片段误识别语言
系统日志确认某英文片段识别为 fi（芬兰语）。修正优先级为手动语言 > 整页语言 > 单段语言，整页识别结果在翻译期间复用，避免每段切换语言。错误提示显示实际语言组合。
已通过误识别优先级及请求链路回归测试，不代表真实整篇翻译已验收。英文文档仍可手动选择英语，0.8.1 也可用此方法绕过自动识别问题。


0.9.0 AI 批量翻译提速
在主界面选择你已配置的 AI/API 翻译源，点击翻译本页或翻译全文。API 翻译现在自动合并相邻文字块，每批最多 8 块、约 6000 字符，同时最多处理 2 批，减少逐块请求等待。长段落仍分段处理。
批量提示要求完整保留数字、单位、否定、引用和术语；返回结果必须逐一对应段落编号。格式不兼容时退回逐段调用，鉴权或网络错误不进行批量重试。成功批次及时保存，可停止后继续。
苹果翻译仍保留作为本机快速选项；本次不自动把苹果译文作为 AI 最终结果，也不自动切换到其他服务。切换到 AI 源会使用其独立缓存。
已通过批次分组、段落对应、漏项/重复/空译文拒绝，以及本机模拟 HTTP 批量、格式回退、鉴权错误测试。尚未实测用户服务的耗时及译文准确率；模型仍可能产生翻译错误。


0.10.0 双栏排版修复
双栏正文分别连续排版，取消跨整页的空白插入和原图切片；同一原文行中被拆散的文字块合并显示，统一字号和段间距，页眉及页脚避让正文。已有译文无需重新请求。
用所提供文档第3页34块现有译文验证了双栏排版，并回归首页四段参考译文；文字框不重叠、完整高度及双向高亮测试通过。复杂图表页面尚未全面验证。旧缓存中的乱码或误译不会被排版操作改写，需要另行修复原文提取及译文内容。


0.10.1 页脚元信息细节
期刊卷期页码、DOI/CN、ISSN、网址与版权保留原文 PDF 的字体、斜体、基线和行列布局，跳过正文式重排及后续翻译请求，避免编号断裂和术语误译。已有缓存的阅读显示立即生效，无需重翻。版权和期刊名此版本保留原文，不强制翻译中文。
用用户首页18块真实缓存验证紧凑页脚及文字不重叠，并验证双向高亮。此规则覆盖常见英文出版信息格式，其他特殊期刊样式可能仍需适配。


0.11.0 跨行首字母与英文段落提取修复
修复 PDFKit 将首行每个字母的选区高度扩大到跨行大写首字母高度，导致多行字母交错的问题。双栏两端对齐的行内大空格不会再轻易拆成孤立词块。
用所提供32页文档第3页验证了 Intensive-care-unit 开头段落完整提取及分栏段落合并；原来34块恢复为17块，双向高亮和无重叠测试通过。
缓存改用新的提取版本：旧缓存文件保留，只有文本及位置完全一致的页面自动恢复。发生提取变化的页面需重新点击翻译，避免复用乱码和错误段落编号。该文档首页缓存兼容测试通过。
目标语言已为中文时，识别为中文的页面直接保留原文和原版式，不调用翻译。中英交替的WPS双语PDF中的中文页可以这样跳过重复处理。
本次验证了原文提取及版面，未替用户调用服务生成新译文；原缓存的译文错误不会凭空被纠正。


0.12.0 苹果初译 + AI 校对
在翻译设置中选择已有的自定义 API 配置，将“翻译方式”改为“苹果初译 + AI 校对”，保留有效的接口地址、模型和密钥后保存。英文论文建议原文语言选择“英语”。苹果部分需要 macOS 15 或更新版本，以及对应系统语言包。
可填写“AI 校对要求”，例如：采用规范医学术语，重点核对统计数值、单位、否定关系与研究结论；不增删内容。术语表仍可单独设置。提示词由 AI 校对阶段使用，不会传给苹果翻译引擎。
每页先显示苹果初稿，段落左侧橙点表示尚未经过 AI 校对；随后将原文及初稿批量发送到所设 API，最多同时两批，成功后以校对结果替换。保留原文的元信息不需要校对。不同模式使用独立缓存，切换后可能需要重新翻译。
中断或校对失败时保留初稿和已完成结果，点击继续即可恢复。只有全部处理完成的页面进入译文导出，未校对初稿不会冒充定稿导出。AI 仍可能出错，重要内容应对照原文核验。
此模式改善先读初稿的等待体验，不保证最终完成速度快于纯 AI 翻译；原文与初稿均会发送到配置的 API，并产生相应调用费用。密钥通过系统钥匙串保存，其有效期和额度由服务商决定。
已通过构建、自检、苹果请求生命周期和语言识别回归测试，以及本机模拟接口的原文+初稿+自定义要求传递、返回格式回退、鉴权错误处理测试。尚未使用用户真实 API 和苹果语言模型完成整篇翻译速度及准确率验收。
